# 抖音开放平台-小游戏试玩素材搜索助手

这是一个给抖音开放平台小游戏试玩素材管理页添加搜索功能的 Chrome 插件。

<img width="410" height="771" alt="image" src="https://github.com/user-attachments/assets/38ca64c0-bd27-41b9-8fb1-4414685d5517" />


## 0、最简单使用方法：
1、下载并解压：
`public-dist/douyin-open-helper-public.zip`

2、打开chrome，打开扩展程序页面的开发者模式，然后点“加载未打包的扩展程序”，选择解压后的文件夹。

3、打开https://developer.open-douyin.com/demogame/list?tab=demogameManage

4、正常登陆开放平台账号，点击chrome右上角的插件图标，打开这个扩展程序，然后刷新页面

5、点击页面上新出现的“搜索助手”悬浮球，然后点击：1、“刷新状态”，2、“开始抓取”，等待抓取完成

6、享受能搜索的试玩素材列表吧！

它能帮你做四件事：

1. 保存当前登录状态，减少重复登录。
2. 一次性抓取试玩管理列表的全部分页数据。
3. 按 `AppID`、试玩游戏名、发布状态、广告计划关联状态快速搜索。
4. 在搜索结果中直接触发网页原本的 `修改`、`显示日志`、`删除` 操作。

## 适合谁用

- 运营同学
- 销售同学
- 商务同学
- 需要频繁查试玩配置、核对状态、打开修改入口的人

## 使用前准备

你需要准备：

1. 一台能打开 Chrome 浏览器的电脑
2. 可以登录抖音开放平台的账号
3. 一份插件文件夹，或者一个打包好的 zip 发布包

如果你拿到的是 zip 文件，先解压到一个你容易找到的位置，比如桌面上的 `douyin-open-helper-public` 文件夹。

## 安装插件

1. 打开 Chrome 浏览器
2. 地址栏输入 `chrome://extensions`
3. 打开右上角的 `开发者模式`
4. 点击左上角 `加载已解压的扩展程序`
5. 选择插件所在文件夹

安装成功后，你会在扩展列表里看到：

`抖音开放平台 - 登录与试玩管理助手`

## 第一次使用

1. 打开目标页面：
   `https://developer.open-douyin.com/demogame/list?tab=demogameManage`
2. 正常登录抖音开放平台
3. 点击浏览器右上角的插件图标，打开插件弹窗
4. 点击 `保存登录`

这样插件会保存当前登录 Cookie。以后浏览器没有完全失效时，可以直接点击 `恢复登录`。

## 页面上的两个入口

安装完成后，你会有两个使用入口：

1. 浏览器右上角的插件弹窗
2. 目标网页右下角的悬浮按钮 `搜索助手`

说明：

- 点击 `搜索助手` 会展开网页内面板
- 再点一次会收起
- 这个按钮可以直接拖拽到你顺手的位置

## 抓取试玩管理列表

1. 打开试玩管理页
2. 等页面表格加载完成
3. 点击 `开始抓取`
4. 等待状态显示 `抓取完成`

抓取完成后，插件会自动保存所有分页结果。

你不需要自己一页一页切。

## 搜索和筛选

插件支持：

- 按 `AppID` 搜索
- 按试玩游戏名搜索
- 按发布状态筛选
- 按是否关联广告计划筛选

使用方法：

1. 在搜索框输入关键词
2. 点击 `搜索`
3. 如果需要，再选择下方筛选条件
4. 查看结果列表
5. 点击某条结果，下面会显示这条记录的详细信息

如果结果很多，可以直接向下滚动整个弹窗查看详情。

## 直接执行操作

每条结果右侧会显示操作按钮，例如：

- `修改`
- `显示日志`
- `删除`

点击后，插件会自动跳到对应页并调用网页原本的操作入口。

说明：

- 如果你在网页内悬浮面板中操作，面板会先自动收起，避免挡住原网页弹窗
- 如果当前按钮本来就不可用，插件也不会强行执行

## 登录相关功能

插件里有三个登录按钮：

- `保存登录`：把当前登录状态保存下来
- `恢复登录`：尝试恢复之前保存的登录状态
- `清除 Cookie`：清空登录信息

建议：

1. 每次成功登录后，都点一次 `保存登录`
2. 如果发现页面频繁掉登录，先试 `恢复登录`
3. 如果账号切换了，再用 `清除 Cookie`

## 常见问题

### 1. 点了开始抓取没反应

先检查：

- 当前页面是不是试玩管理页
- 表格是不是已经加载出来
- 页面是不是还在登录中

### 2. 搜不到某个试玩

先检查：

- 是否已经先执行过抓取
- 搜索词是不是过于模糊
- 是否需要再配合发布状态或广告计划筛选

### 3. 操作按钮弹不出网页窗口

先检查：

- 当前网页有没有被浏览器拦截弹层
- 页面是不是还停留在试玩管理页
- 是否重新抓取过最新列表

### 4. 悬浮按钮挡住页面

可以直接拖动 `搜索助手` 到页面其他位置。

## 更新插件

如果你拿到的是新版本：

1. 替换本地插件文件夹
2. 打开 `chrome://extensions`
3. 找到本插件
4. 点击刷新图标

## 建议的日常使用顺序

1. 打开试玩管理页
2. 确认登录状态
3. 点击 `恢复登录` 或正常登录
4. 点击 `开始抓取`
5. 用搜索框查目标试玩
6. 查看详情
7. 需要时直接点 `修改`、`显示日志` 或 `删除`
